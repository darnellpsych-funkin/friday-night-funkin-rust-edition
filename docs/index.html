Friday Night Funkin'
Rust Edition

Una reconstrucción del juego con Rust compilado a WebAssembly, pensada para correr en el navegador junto a la versión JavaScript.

Ver código Versión JavaScript

Estado del proyecto

  • En desarrollo. Esta página es la presentación del proyecto; el juego jugable todavía está en construcción.
  • El primer módulo en Rust es el juicio de notas (Sick, Good, Bad, Shit y Fallo), compilado a WebAssembly. Ya existe en la versión JavaScript como prueba.
  • Los assets de personajes provienen de Bambi-Slice y conservan sus licencias originales.

Compilar el módulo WebAssembly

Requiere Rust y el target wasm32-unknown-unknown.

rustup target add wasm32-unknown-unknown
cargo build --release --target wasm32-unknown-unknown

Aviso

Friday Night Funkin' Rust Edition es un proyecto de fan y no es oficial. Friday Night Funkin' pertenece a The Funkin' Crew.
